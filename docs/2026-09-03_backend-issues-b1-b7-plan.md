# Backend Issues B1–B7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the seven open backend GitHub issues (B1–B7) so the frontend can drop its local OpenAPI patches, hand-written types, and partial-save workarounds.

**Architecture:** Gin + pgx/v5 + sqlc + swaggo, module `fleet`, clean-architecture layers (`dto` → `handler` store → `gen` sqlc → SQL). Response shaping happens in `to*Response` mappers in the `handler` package; filtered lists are assembled by `FilteredListHandler` via the `listSpec`/`filter.Where` builders; the OpenAPI spec is generated by swaggo into `docs/`.

**Tech Stack:** Go 1.26, Gin, pgx/v5, sqlc v1.29.0, swaggo/swag v1.16.4, shopspring/decimal, golang-migrate.

**Spec:** The seven issues at https://github.com/jesuslab135/Go-Logistics/issues (B1–B7), each sourced from `docs/BACKEND-REQUIREMENTS.md` in the frontend repo. Acceptance criteria are quoted per task.

## Global Constraints

- **Every commit must pass the full CI gate** (`.github/workflows/ci.yml`), in order: `go build ./...`, `go vet ./...`, `gofmt -l .` (must be empty), `go test ./...`, then **byte-identical regeneration drift checks** for both sqlc (`git diff --exit-code internal/db/gen`) and swaggo (`git diff --exit-code docs`).
- **No test may require a database.** The suite is 100% DB-free (no testcontainers, no mocks of `*gen.Queries` — `emit_interface: false`). Tests are: pure table-driven logic, SQL-string-builder assertions (see `internal/http/handler/listquery_test.go`), generated-spec assertions reading `docs/swagger.json` (see `internal/http/handler/openapi_spec_test.go`), and `httptest`/`gin.CreateTestContext` binding tests (see `internal/http/handler/validation_test.go`). DB-level guarantees (transaction rollback, GROUP BY execution) are verified by a **local manual smoke** against the dev DB, documented in the relevant task — never by a CI test.
- **Regenerate after every change that affects generated output:**
  - sqlc: `sqlc generate` (after editing `internal/db/queries/*.sql` or migrations).
  - swaggo: `swag init -g main.go -d ./cmd/api,./internal/http/handler,./internal/http/dto,./internal/auth,./internal/platform/storage --parseDependency --parseInternal -o docs`
  Both binaries must be the pinned versions (`sqlc@v1.29.0`, `swag@v1.16.4`) or the drift check fails.
- **There is no `openapi/Fleet-Go-API.yaml` in this repo.** The frontend's reference to it maps to this backend's `docs/swagger.yaml` / `docs/swagger.json`. All "OpenAPI" changes here mean swaggo annotations regenerated into `docs/`.
- **Tenant scoping is always in SQL** via `company_id` (or a join to a company-owning parent), seeded as the first `filter.Where` predicate: `filter.NewWhere(1).Add("<alias>.company_id", filter.Eq, middleware.CompanyFromContext(ctx))`. Never post-filter in Go.
- **Error shape** is `{"error":{"code","message","details"}}`. Field-addressable 422s use `apierr.Validation(map[string]string{...})` keyed by the JSON field name (or `custom_fields.<key>`).
- **Commit style:** one thematic commit per issue (per user preference: thematic commits, single author). Commit trailers/authorship are a **pre-execution decision** — see "Open Decision: commit attribution" at the bottom before the first commit.
- **Housekeeping:** an empty untracked stray directory `internal/db/migrations;M` exists on disk (not tracked by git, from an accidental shell command). Remove it once (`rmdir "internal/db/migrations;M"`) so it stops appearing; it affects nothing.

## Task 2: B5 — Correct the custom_fields OpenAPI schema

**Priority:** P1. **Acceptance:** No supported `custom_fields` property is declared as `type: array` of integers; regenerated TypeScript is a string-keyed object, not `number[]`/`any[]`; create/update/read round-trip values unchanged; invalid values still return field-addressable 422s using `custom_fields.<key>`.

Root cause: every `custom_fields` field is `json.RawMessage` (Go `[]byte`), which swaggo renders as `{items:{type:integer},type:array}`. The fix is a swaggo **type override** on each field so the schema renders as a free-form object. The Go type stays `json.RawMessage`; binding, storage, and `customfield.Validate` (which already keys errors as `custom_fields.<key>`) are untouched — so round-trip and 422 behavior are unchanged by construction.

// facetQuery builds a grouped-count statement over the same FROM/WHERE a list
// uses, minus the grouped dimension's own filter (the caller omits it). No LIMIT:
// facet counts describe the whole filtered set, so they stay exact as a page
// scrolls. labelExpr is the human label column (equal to groupExpr when the value
// is its own label).
func facetQuery(from string, where *filter.Where, groupExpr, labelExpr string) (string, []any) {
	sql := "SELECT " + groupExpr + ", " + labelExpr + ", count(*) " + from
	if cond := where.SQL(); cond != "" {
		sql += " WHERE " + cond
	}
	sql += " GROUP BY " + groupExpr + ", " + labelExpr
	return sql, where.Args()
}

```go
func (s *AssetStore) Create(ctx context.Context, in dto.CreateAssetRequest) (dto.AssetResponse, error) {
	if err := validateCustomFields(ctx, s.q, "assets", in.CustomFields); err != nil {
		return dto.AssetResponse{}, err
	}
	company := middleware.CompanyFromContext(ctx)

	// Asset-only: unchanged single-write path.
	if in.Vehicle == nil && in.Trailer == nil {
		r, err := createAssetRow(ctx, s.q, company, in)
		if err != nil {
			return dto.AssetResponse{}, err
		}
		return s.withSubtypes(ctx, s.response(ctx, r))
	}

	// Asset + subtype: both writes in one transaction, or neither.
	var created gen.Asset
	err := inTx(ctx, s.pool, s.q, func(qtx *gen.Queries) error {
		r, err := createAssetRow(ctx, qtx, company, in)
		if err != nil {
			return err
		}
		created = r
		if in.Vehicle != nil {
			if _, err := upsertVehicleTx(ctx, qtx, r.ID, company, *in.Vehicle); err != nil {
				return err
			}
		}
		if in.Trailer != nil {
			if err := validateTrailerClassificationsTx(ctx, qtx, company, in.Trailer.ClassificationID, in.Trailer.Classification2ID); err != nil {
				return err // 422 rolls back the asset insert
			}
			if _, err := upsertTrailerTx(ctx, qtx, r.ID, company, *in.Trailer); err != nil {
				return err
			}
		}
		return nil
	})
	if err != nil {
		return dto.AssetResponse{}, err
	}
	return s.withSubtypes(ctx, s.response(ctx, created))
}
```
