# Go-Logistics (`fleet`)

A Go rewrite of a Django REST fleet-management backend. Clean-architecture layout
with a PostgreSQL persistence layer generated by [sqlc](https://sqlc.dev) and an
HTTP API served with [Gin](https://gin-gonic.com).

- **Language/runtime:** Go 1.26+
- **Database:** PostgreSQL 14+
- **Auth:** JWT (HS256 access + refresh), bcrypt passwords
- **Module path:** `fleet`

> Status: the full request pipeline is wired end-to-end, but only the
> `companies` resource is exposed as a REST endpoint so far. Every other table
> has domain structs + generated queries and follows the same handler template.

---

## Project layout

```
cmd/
  api/            HTTP server entrypoint
  cli/            admin CLI (e.g. set an employee password)
internal/
  config/         env-driven configuration
  auth/           JWT token service + bcrypt helpers
  db/
    migrations/   golang-migrate SQL (000001 schema, 000002 employee password)
    queries/      sqlc query sources (*.sql)
    gen/          sqlc-generated code (do not hand-edit)
    pool.go       pgx pool factory (registers the decimal codec)
  domain/         hand-written domain structs (one package per aggregate)
  http/
    dto/          request/response types
    handler/      Store implementations, auth handler, router
    middleware/   request id, logging, recovery, CORS, JWT auth
  platform/       apierr, paginate, filter, storage, crud (cross-cutting infra)
```

## Run it locally (fresh laptop)

### 1. Prerequisites

- **Go 1.26+** — https://go.dev/dl/
- **PostgreSQL** — a local install, or Docker (below)
- **golang-migrate CLI** — to apply the migrations:
  ```sh
  go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest
  ```
  (installs to `$(go env GOPATH)/bin` — make sure that's on your `PATH`)

### 2. Clone

```sh
git clone https://github.com/jesuslab135/Go-Logistics.git
cd Go-Logistics
go mod download
```

### 3. Start PostgreSQL

Either use an existing server, or spin one up with Docker:

```sh
docker run --name fleet-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=fleet \
  -p 5432:5432 -d postgres:16
```

### 4. Configure environment

```sh
cp .env.example .env
```

Edit `.env` — at minimum set `DATABASE_URL` and a strong `JWT_SECRET`:

```
DATABASE_URL=postgres://postgres:postgres@localhost:5432/fleet?sslmode=disable
JWT_SECRET=please-change-me
```

`.env` is loaded automatically by both `cmd/api` and `cmd/cli`.

### 5. Apply migrations

```sh
migrate -path internal/db/migrations -database "$DATABASE_URL" up
```

(Windows PowerShell: use `$env:DATABASE_URL` or paste the DSN inline.)

### 6. Run the API

```sh
go run ./cmd/api
# {"level":"INFO","msg":"http server listening","addr":":8080","env":"development"}
```

Health check:

```sh
curl http://localhost:8080/healthz
# {"status":"ok"}
```

## Create the first user and log in

There is no public sign-up endpoint yet, and `/api/v1/*` requires a token, so the
first account is seeded directly in the database. Connect with `psql "$DATABASE_URL"`
(or any client) and run:

```sql
-- 1) a company (tenant)
INSERT INTO company (name, tax_id, address, created_at, phone, email, website,
                     logo, city, region, postal_code, country, timezone,
                     currency, system_of_measurement)
VALUES ('Acme', 'ACME-001', '', now(), '', '', '', NULL, '', '', '',
        'MX', 'America/Mexico_City', 'MXN', 'metric')
RETURNING id;   -- assume 1

-- 2) an admin role for that company
INSERT INTO role (company_id, name, is_admin, permissions)
VALUES (1, 'Admin', true, '{}')
RETURNING id;   -- assume 1

-- 3) an employee (the login identity)
INSERT INTO employee (default_company_id, role_id, first_name, last_name,
                      employee_id, email, mobile_phone, work_phone, job_title,
                      license_class, license_number, license_state, street_address,
                      city, region, postal_code, country, updated_at)
VALUES (1, 1, 'Admin', 'User', 'EMP-001', 'admin@example.com',
        '', '', '', '', '', '', '', '', '', '', 'MX', now())
RETURNING id;
```

Set the password with the CLI:

```sh
go run ./cmd/cli setpass --email admin@example.com --password supersecret1
```

Log in to get tokens:

```sh
curl -X POST http://localhost:8080/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@example.com","password":"supersecret1"}'
# {"access_token":"...","refresh_token":"...","token_type":"Bearer","expires_in":3600}
```

Call a protected endpoint:

```sh
TOKEN=<access_token>
curl http://localhost:8080/api/v1/companies -H "Authorization: Bearer $TOKEN"
```

## API surface

| Method | Path                     | Auth  | Description                 |
|--------|--------------------------|-------|-----------------------------|
| GET    | `/healthz`               | no    | Liveness                    |
| POST   | `/auth/login`            | no    | Email + password -> tokens  |
| POST   | `/auth/refresh`          | no    | Refresh token -> new tokens |
| GET    | `/api/v1/companies`      | yes   | List (`?page`,`?page_size`) |
| POST   | `/api/v1/companies`      | yes   | Create                      |
| GET    | `/api/v1/companies/:id`  | yes   | Get by id                   |
| PUT    | `/api/v1/companies/:id`  | yes   | Update                      |
| DELETE | `/api/v1/companies/:id`  | yes   | Delete                      |

## Environment variables

| Variable             | Default                     | Notes                          |
|----------------------|-----------------------------|--------------------------------|
| `DATABASE_URL`       | — (**required**)            | pgx connection string          |
| `JWT_SECRET`         | — (**required**)            | HS256 signing key              |
| `APP_ENV`            | `development`               | `production` enables Gin release mode |
| `HTTP_ADDR`          | `:8080`                     | Listen address                 |
| `CORS_ORIGINS`       | `*`                         | Comma-separated allowlist      |
| `JWT_ISSUER`         | `fleet`                     |                                |
| `JWT_ACCESS_TTL`     | `1h`                        | Go duration                    |
| `JWT_REFRESH_TTL`    | `168h`                      | Go duration                    |
| `STORAGE_LOCAL_ROOT` | `./uploads`                 | Local file storage root        |
| `STORAGE_BASE_URL`   | `/media`                    | Public URL prefix for uploads  |
| `PAGE_DEFAULT_SIZE`  | `25`                        | Default page size              |
| `PAGE_MAX_SIZE`      | `100`                       | Max page size                  |

## Development

Build / vet / format:

```sh
go build ./...
go vet ./...
gofmt -l .
```

Regenerate the sqlc layer after editing `internal/db/queries/*.sql` or the schema:

```sh
go install github.com/sqlc-dev/sqlc/cmd/sqlc@v1.29.0
sqlc generate
```

Roll a migration back:

```sh
migrate -path internal/db/migrations -database "$DATABASE_URL" down 1
```
